# 🧪 AI Sandbox

**AI の実験用ボックス。好きなだけ壊して、学んで、進化しろ。**

> ryota DB (本番) から完全分離された AI 専用の実験環境。
> ここでの失敗は学習データ。成功したものだけ本番に昇格する。

---

## コンセプト

| | ryota DB (本番) | AI Sandbox (ここ) |
|---|---|---|
| 役割 | 安定した本番 DB + MCP | AI の自由な実験場 |
| AI 権限 | 承認必須 | 自由に実験 OK |
| ブランチ | `main` 保護 | いくらでも分岐 OK |
| 壊れたら | ロールバック必須 | レポートに記録して次へ |
| データ | 不変性保証 (Merkle Tree) | 実験データ + レポート蓄積 |

## ルール

1. **自由にやれ。ただし証拠は残せ。**
   - 全ての実験結果はレポートとして蓄積する
   - 成功も失敗も記録する
   - レポートがなければ実験は存在しないのと同じ

2. **本番 (ryota DB) には直接触るな。**
   - ここで検証済みのコードだけが昇格資格を持つ
   - 昇格時は PR + レビュー必須

3. **ブランチは自由に切れ。**
   - 実験ごとにブランチを切る
   - 失敗したブランチも消さない（学習データ）

## 構造

```
ai-sandbox/
├── README.md              ← この説明書
├── experiments/            ← 実験コード
│   └── {experiment-name}/  ← 実験ごとのディレクトリ
├── reports/                ← 実験レポート蓄積
│   └── {date}_{topic}.md   ← 何を試して何が起きたか
└── graduated/              ← 本番昇格済み（参照用）
```

## テクノロジースタック

- **Runtime**: Python 3.12+ / uv
- **Linter**: Ruff
- **Server**: Granian
- **ORM**: SQLModel
- **Container**: OrbStack
- **Local LLM**: MLX-LM (Mac Studio M3 Ultra)

## 起源

元 `ryota-db` リポの `DBPPC` ブランチから独立。
本番 DB との依存関係を完全に切り、AI が安全に暴れられる場所として再構築。
